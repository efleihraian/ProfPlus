# Identitatea ProfPlus

Actualizat: 2026-10-04 · versiune 0.9.2.

Numele produsului este **ProfPlus**, pe website și în viitoarele aplicații Android/iOS. Interfața, etichetele accesibile, titlul paginii, biblioteca, instrucțiunea asistentului AI, numele indexurilor nou create, pachetul aplicației și documentația folosesc ProfPlus. Paleta albastru/emerald și simbolul P se păstrează.

Repository privat: [ProfPlus](https://github.com/ProfOS-Edu/ProfPlus). Numele afișat al organizației GitHub este ProfPlus; identificatorul organizației rămâne `ProfOS-Edu`. Integrarea Supabase afișează noul repository după redenumire.

## Compatibilitate

Identificatorii existenți nu se înlocuiesc doar pentru branding:

- Adresa pilotului Sites rămâne `https://profos-chat.cosminsoames.chatgpt.site`; schimbarea titlului Sites nu schimbă URL-ul. Domeniul propriu va fi configurat separat.
- Cookie-ul `profos-auth` și cheile locale `profos-theme`, `profos-remember-preferences`, `profos-chat-id`, `profos-selection-*` rămân stabile, pentru păstrarea sesiunilor/preferințelor. Nu sunt texte afișate în interfață. Eventuala migrare necesită compatibilitate și probe separate.
- Identificatorii conturilor, proiectelor, conversațiilor, fișierelor, indexurilor și site-ului rămân identici. Nu se rescriu documentele originale, mesajele istorice ale utilizatorilor sau numele existente ale colecțiilor externe.
- Bundle ID Apple existent `profplus.ro` rămâne stabil; el este un identificator al aplicației, nu dovada deținerii unui domeniu web. Nu se redenumește înainte de o decizie de distribuție/migrare.

Rebrandingul nu adaugă date colectate, furnizori, trackere, permisiuni sau acces public. Condițiile GDPR/DPIA din documentația proiectului rămân deschise până la verificarea și aprobarea lor.
